# UniShare — bản demo thuyết trình

Bản rút gọn từ website học liệu, gồm 12 môn tiêu biểu.

- 6 môn giữ chức năng thi trực tiếp trên web cùng dữ liệu câu hỏi cần thiết.
- Các môn còn lại ưu tiên tài liệu Google Drive/Azota; không mang toàn bộ ngân hàng đề sang bản demo.
- Không kèm Firebase, đăng nhập Google, hồ sơ người dùng, PK bạn bè hay cấu hình backend của website chính.
- Các link Google Drive/Azota có sẵn trong trang môn học được giữ nguyên.

Chạy bằng Live Server hoặc web server tĩnh để các chức năng tải dữ liệu hoạt động ổn định.
